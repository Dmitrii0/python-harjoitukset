# Sairaalapeli

## Pelin idea

Sairaalapeli on komentorivillä pelattava tekstiseikkailupeli. Pelaaja saapuu sairaalaan ja antaa aluksi omat perustietonsa, kuten nimen, iän, pituuden ja painon.

Pelin aikana pelaaja voi mennä vastaanotolle, mitata verenpaineen, käydä verikokeessa ja tarkastella tehtyjä tutkimuksia sekä lääkärin suosituksia.

Pelaajan valinnat vaikuttavat siihen, miten peli etenee.
